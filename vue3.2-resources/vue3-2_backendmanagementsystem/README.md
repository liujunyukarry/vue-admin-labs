# Vue 3.2 后台管理系统：资源与学习资料

这是一个以 `resource/` 为根的学习资源仓库，包含后台页面片段、图标、SCSS 样式、路由资料、国际化配置、接口文档和打包模板。**仓库根目录目前没有可直接运行的 `package.json`**；不要误写成克隆后可在根目录 `npm run dev`。

## 目录索引

| 路径 | 用途 |
| --- | --- |
| `resource/接口文档/` | 电商管理后台 API 规范 |
| `resource/路由页面/` | 登录、商品、订单、权限等 Vue 页面示例 |
| `resource/路由配置/` | 路由相关学习资料 |
| `resource/icons/` | 图标及 SVG |
| `resource/styles/` | 全局样式与 Element 样式资源 |
| `resource/国际化配置/` | 国际化学习资料 |
| `resource/husky规范/` | Git 提交工具相关资料 |
| `resource/模板/vue_3.2.zip` | 原有压缩模板，未在此次整理中解压或替换 |
| `resource/笔记/` | 知识笔记 |

## 使用约定

如要启动项目，应先检查 `resource/模板/vue_3.2.zip` 的内部结构和实际依赖，再根据模板文档选择对应启动命令。接口文档内的 `127.0.0.1` 是示例本地服务地址，不代表现成可访问的线上后端。

保留原始资源文件位置，避免教学说明或导入路径失效。尚未验证压缩模板能否安装、编译或连接 API。
